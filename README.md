# Python for Health Data

My Python practice repo as I learn health informatics. Each folder is a small, self-contained exercise on real-world-style (synthetic or public) health data.

## Topics
- [ ] pandas basics: cleaning, joining, grouping
- [ ] Calling REST APIs and parsing JSON
- [ ] FHIR resources with `requests` (HAPI FHIR R4 test server)
- [ ] Data visualization with matplotlib
- [ ] Machine learning with scikit-learn

## Layout
```
notebooks/   Jupyter notebooks, one per exercise
data/        local data (git-ignored; synthetic or public only)
```

## Tools
Python, pandas, NumPy, requests, matplotlib, scikit-learn, Jupyter

## Data note
Only synthetic (e.g. Synthea) or public datasets. No real patient information.

Main project: [fhir-ml-pipeline](https://github.com/isaiahj3-MSHI/fhir-ml-pipeline)
